Política de privacidad

Última actualización: 18 de octubre de 2026

"Curiosidades de la Ingeniería Uploader" (la "herramienta") es una utilidad de uso personal que funciona solo en el ordenador del creador del canal Curiosidades de la Ingeniería para subir los vídeos del canal a su propia cuenta de TikTok.

Qué datos se usan

  • El token de acceso que entrega TikTok al autorizar la herramienta, y la información básica de la cuenta (identificador y nombre) que TikTok devuelve con él.
  • Los vídeos y textos que el propio creador decide subir.

Dónde se guardan

El token se guarda solo en el ordenador del creador. La herramienta no usa servidores propios, cookies, analítica ni publicidad, y con ella no se recogen datos de otras personas ni se venden o comparten con terceros; solo se envían a TikTok los vídeos que se suben. (El sitio web del canal funciona aparte y se explica más abajo.)

Sitio web curiosidadesdelaingenieria.com

El sitio web del canal es independiente de la herramienta anterior y funciona así:

  • Medición de visitas: se usa Cloudflare Web Analytics para saber cuántas personas visitan cada página y desde qué países, navegadores y webs llegan. Según Cloudflare, no usa cookies ni identifica a cada visitante; los datos son agregados y los trata Cloudflare.
  • "Me gusta": para no contar dos veces al mismo visitante se guarda un identificador anónimo (una huella calculada con la IP y el navegador y una clave secreta). No se guarda la IP.
  • Formulario "Propón un tema": el correo es obligatorio; también se guarda el tema, el detalle y, si lo indicas, tu nombre o usuario. Se conservan en la base de datos SQLite del servidor del canal junto con la fecha y versión del consentimiento; solo el equipo puede verlos desde la administración y se usan para valorar la propuesta y contactarte sobre ella, nunca para publicidad. Para limitar el spam también se conserva un identificador anónimo calculado con la IP y el navegador (la IP no se guarda). Si están activados los avisos internos por correo, la propuesta se envía al buzón de administración mediante el proveedor de correo. Puedes pedir que borremos tu propuesta y los datos asociados escribiendo por el canal de contacto.
  • Vídeos: los vídeos se muestran desde YouTube en modo de privacidad mejorada y no se carga nada de YouTube hasta que pulsas reproducir.
  • Alojamiento: el sitio se aloja en un servidor del propio creador y recibe el tráfico a través de Cloudflare, que puede tratar los datos técnicos de la conexión para entregar la web. No hay publicidad ni se venden datos.

Para pedir que se borre una propuesta o cualquier dato asociado, escribe por el canal de contacto.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde la app de TikTok: Ajustes y privacidad → Seguridad → Apps y servicios con permisos. Al revocarlo, el token deja de funcionar.

Contacto

A través del canal de YouTube @CuriosidadesDeIngenieria.

English summary

This personal tool runs only on the channel creator's computer. It uses the TikTok access token and basic account info returned by TikTok Login solely to upload the channel's own videos to its own TikTok account. The token is stored locally; the tool uses no servers of its own, cookies, analytics or ads, and no data is sold or shared. Access can be revoked at any time in the TikTok app settings.

The channel's website (curiosidadesdelaingenieria.com) is separate: it uses Cloudflare Web Analytics (aggregate visit counts; no cookies according to Cloudflare), stores anonymous like counts and topic suggestions. Topic suggestions require an email address, stored with the proposal in the channel's private server database and used only to review it and contact you about it, not for advertising. You can request deletion through the channel's YouTube contact link. YouTube videos load only when you press play; the site uses no ads and does not sell data.
